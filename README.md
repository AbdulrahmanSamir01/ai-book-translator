# 📚 Ai Book Translator & EPUB Builder

أداة برمجة لترجمة الكتب والمستندات بصيغة **Markdown** من الإنجليزية إلى العربية باستخدام **Groq API**، مع الحفاظ على التنسيق والقاموس المتصل، وتجميع المخرجات في كتاب **EPUB 3** احترافي يدعم الاتجاه من اليمين إلى اليسار (RTL).

---

## 🚀 المميزات (Features)

* **ترجمة ذكية متصلة السياق**: تتبع الملخص التراكمي للصول وقاموس المصطلحات (Glossary) تلقائياً عبر ملف `memory.json`.
* **معالجة القيود والـ Rate Limits**: معالجة خطأ `429` عبر إيقاف مؤقت زمني تلقائي (60 ثانية) وإعادة المحاولة.
* **استئناف العمل الذكي (Skip Checkpoint)**: تخطي ترجمة الملفات المعالجة سابقاً في حال انقطاع السكربت.
* **دعم كامل لـ RTL والخطوط العربية**: بناء كتاب EPUB مُصمم خصيصاً للقراءة العربية مع عزل الأكواد البرمجية (LTR).
