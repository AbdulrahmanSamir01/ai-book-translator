## 8.74.2. تهيئة Vim

**افتراضياً، يعمل vim في وضع غير متوافق مع vi (vi-incompatible mode). قد يكون هذا أمراً جديداً للمستخدمين الذين استخدموا محررات أخرى في الماضي. تم إدراج إعداد "nocompatible" أدناه لتسليط الضوء على حقيقة أنه يتم استخدام سلوك جديد. كما يذكر أولئك الذين يرغبون في التغيير إلى وضع "compatible" أنه يجب أن يكون هذا هو الإعداد الأول في ملف التهيئة. هذا ضروري لأنه يغير إعدادات أخرى، ويجب أن تأتي التجاوزات بعد هذا الإعداد. قم بإنشاء ملف تهيئة افتراضي لـ vim عن طريق تشغيل ما يلي:**

**cat > /etc/vimrc << "EOF"**
" Begin /etc/vimrc

" Ensure defaults are set before customizing settings, not after
source $VIMRUNTIME/defaults.vim
let skip_defaults_vim=1

set nocompatible
set backspace=2
set mouse=
syntax on
if (&term == "xterm") || (&term == "putty")
set background=dark
endif

" End /etc/vimrc
**EOF**

**يجعل إعداد set nocompatible برنامج vim يتصرف بطريقة أكثر فائدة (وهو الافتراضي) من الطريقة المتوافقة مع vi. قم بإزالة "no" للحفاظ على سلوك vi القديم. يسمح إعداد set backspace=2 بالرجوع (backspacing) فوق فواصل الأسطر، والمسافات البادئة التلقائية، وبداية الإدخال. يفعّل معامل syntax on تمييز الصيغة (syntax highlighting) في vim. يفعّل إعداد set mouse= اللصق الصحيح للنصوص باستخدام الفأرة عند العمل في بيئة chroot أو عبر اتصال عن بعد. أخيراً، تقوم جملة if مع إعداد set background=dark بتصحيح تخمين vim للون خلفية بعض محاكيات الطرفية، مما يمنح تمييز الصيغة مخطط ألوان أفضل للاستخدام على الخلفية السوداء لهذه البرامج.**

يمكن الحصول على توثيقات للخيارات المتاحة الأخرى عن طريق تشغيل الأمر التالي:

**vim -c ':options'**

### ملاحظة

افتراضياً، يقوم vim بتثبيت ملفات التدقيق الإملائي للغة الإنجليزية فقط. لتثبيت ملفات التدقيق الإملائي للغتك المفضلة، انسخ ملفات .spl واختيارياً ملفات .sug الخاصة بلغتك وترميز الأحرف من runtime/spell إلى /usr/share/vim/vim92/spell/.

لاستخدام ملفات التدقيق الإملائي هذه، يلزم إجراء بعض التهيئة في /etc/vimrc، على سبيل المثال:

set spelllang=en,ru
set spell

لمزيد من المعلومات، راجع runtime/spell/README.txt.
